# Student Management REST API

Spring Boot 4.0.8, Java 17, Spring Data JPA, MySQL. Implements the assignment's six REST endpoints. No frontend is required by the assignment.

## Run with Docker (recommended)

Install Docker Desktop and start it. In this folder run:

```sh
docker compose up --build
```

The image build runs the integration tests against H2; the running application uses MySQL. Wait for the application to start, then use http://localhost:8080/api/students. An empty database returns `[]`.

Stop with `docker compose down`. Database records persist in the Docker volume. Development database credentials are in compose.yaml; change them before deploying publicly.

## Run without Docker

Install JDK 17 or later, Maven 3.6.3 or later, and MySQL 8.4. Check `java -version` and `mvn -version`. Execute `database/setup.sql` as a MySQL administrator:

```sh
mysql -u root -p < database/setup.sql
mvn clean verify
mvn spring-boot:run
```

Configuration is in `src/main/resources/application.properties`. Override `DB_URL`, `DB_USERNAME`, `DB_PASSWORD`, or `PORT` through environment variables if needed. The default password is a local development example. Hibernate creates/updates the schema automatically; use migrations for a production deployment.

To run tests without MySQL: `mvn test`. Tests use an isolated H2 database, exercise all six endpoints, validation, malformed input, and missing records. They do not verify MySQL-specific behavior.

## API

| Method | Path | Success |
|---|---|---|
| POST | /api/students | 201 Created with Location header |
| GET | /api/students | 200, array |
| GET | /api/students/{id} | 200, student |
| PUT | /api/students/{id} | 200, updated student |
| DELETE | /api/students/{id} | 204, no body |
| GET | /api/students/course/{course} | 200, array |

POST and PUT accept the full student payload; ID is generated by the database:

```json
{"name":"Asha Rao","email":"asha@example.com","course":"Java","age":21}
```

Name and course are required and at most 100 characters; email is required, valid, and at most 254 characters; age is required and between 1 and 150. Duplicate emails are allowed because the assignment does not require uniqueness. Course filtering ignores case and trims surrounding whitespace. URL-encode course names containing spaces. Missing IDs return 404. Invalid input returns 400 with Problem Details; field validation includes an `errors` object. Empty lists return 200 with `[]`. PUT requires all four fields.
